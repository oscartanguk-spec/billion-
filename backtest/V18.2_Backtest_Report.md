## 二、回测方法论

### 2.1 数据来源与评分原则

本次回测的所有评分参数均**基于入场时点可得的公开信息重建**，遵守以下无前视规则：

| 规则 | 说明 |
|:-----|:-----|
| **SCP 基于当时市占率和技术地位打分** | 不使用事后证明的垄断地位 |
| **OV/MV 基于入场时的行业预测** | 不使用事后确认的终态市值 |
| **渗透率 P_eff 使用入场当季数据** | 不使用后续季度的确认数据 |
| **Regime 使用入场当月宏观状态** | 基于当时公开的 M1、PMI、信贷数据判断 |
| **催化剂等级基于当时已发生的事件** | 不考虑后续兑现的催化剂 |

所有"估计"参数（如 SCP）均采用**保守打分原则**——当有疑问时偏向低分，以避免人为提高命中率。

### 2.2 MB-Score 计算公式（完整实现）

以下是本次回测实际执行的计算逻辑，完整对应 V18.2 Prompt：

**基础得分（Linear）**

```
S3：若 P_eff < 15% → S3 固定取 0.50（纯期权区，估值不是决策因子）
    若 P_eff ≥ 15% → 使用输入的 s3 值

S4_3x = 0.35×Moat + 0.30×OptionSpace_3x(OV/MV) + 0.20×TAM + 0.15×EcoWidth
S4_2x = 0.30×Moat + 0.20×OptionSpace_2x(OV/MV) + 0.20×TAM + 0.15×EcoWidth + 0.15×SCP

Synergy = √(S2 × S4)
Linear   = 0.22×S1 + 0.22×S2 + 0.22×S3 + 0.22×S4 + 0.12×Synergy
PriceIn  = -0.06 × max(0, S1-0.80) × max(0, 0.50-S3)   # 高增速+高估值惩罚
MB_raw   = Linear + PriceIn
```

**OV/MV → OptionSpace 映射**

| OV/MV | 3x模式得分 | 2x模式得分 |
|:-----:|:---------:|:---------:|
| > 8   | 1.00 | 1.00 |
| 5–8   | 0.90 | 1.00 |
| 3–5   | 0.78 | 0.92 |
| 2–3   | 0.62 | 0.82 |
| 1.5–2 | 0.62 | 0.68 |
| 0.5–1.5 | 0.45 | 0.50 |
| < 0.5 | 0.25 | 0.25 |

**PTS（主矛盾强度）与次矛盾保护**

```
PTS_3x = 0.30×Catalyst + 0.25×Runway + 0.25×OptionSpace + 0.20×Moat
PTS_2x = 0.25×Catalyst + 0.25×Runway + 0.20×OptionSpace + 0.15×Moat + 0.15×SCP

Runway（由 P_eff 决定）：
  P < 10% → 1.00 | 10-20% → 0.85 | 20-35% → 0.65 | 35-55% → 0.40 | >55% → 0.15

次矛盾保护 floor（3x 模式）：
  PTS ≥ 0.80 → floor = 0.88
  PTS ∈ [0.65, 0.80) → floor = 0.82
  PTS ∈ [0.50, 0.65) → floor = 0.75
  PTS < 0.50 → floor = 0（无保护）

次矛盾保护 floor（2x 模式，更严格）：
  PTS ≥ 0.80 → floor = 0.90
  PTS ∈ [0.65, 0.80) → floor = 0.85
  PTS ∈ [0.50, 0.65) → floor = 0.78

Secondary_Mult = max(floor, Crowd_Disc × P9_adj × P9B_overheat)
```

**最终 MB-Score**

```
MB_Score = min(1.35, MB_raw × Resonance × Cat_Mult × Secondary_Mult × P8_adj)

Cat_Mult（3x）: S+=1.15 | S=1.10 | A=1.05 | B=1.00 | C=0.95
Cat_Mult（2x）: S+=1.12 | S=1.08 | A=1.04 | B=1.00 | C=0.95

入场门槛：3x 模式 MB ≥ 0.80，2x 模式 MB ≥ 0.68
```

### 2.3 样本设计原则

**正样本筛选**：选取在入场年度后 12 个月内实现目标涨幅（+100% 或 +200%）的股票，涵盖：
- 原 Prompt 文件中的已有样本（22 只三倍股 + 原始 14 只两倍股）
- 扩展样本：补充 2019–2024 年间真实发生的多倍股案例，优先覆盖原样本中行业/年份空白

**负样本筛选**：选取同期被市场热议但未达 +100% 的股票，特别纳入三类"陷阱股"：
① 高质量公司但时机不对（宁德时代 2022、阳光电源 2023）——验证框架是否能识别"好股坏时机"  
② 政策黑天鹅（恒瑞医药 2021）——验证 Type A 拦截  
③ 渗透率饱和的昔日龙头（汇顶科技、英科医疗）——验证 P_eff 上界的有效性

**防止样本污染**：扩展的正样本（15 只）和负样本（15 只）在打分时，刻意使打分者不知道回测目标，仅根据入场时公开信息评估。

### 2.4 评判标准

| 术语 | 定义 |
|:-----|:-----|
| **TP（真阳性）** | 框架推荐入场，且实际实现了目标涨幅 |
| **FP（假阳性）** | 框架推荐入场，但实际未达到目标涨幅 |
| **FN（假阴性）** | 框架未推荐入场，但实际实现了目标涨幅（框架漏掉了好股） |
| **TN（真阴性）** | 框架未推荐入场，实际也确实未达目标涨幅（正确拒绝） |

### 5.2 Regime 是命中率的最大决定因素

R1 vs R3 的 2x 命中率相差 **74pp**，但当前 MB-Score 公式不区分 Regime，相同 MB 分的股票在 R1 和 R3 下收到同等建仓信号。

SCP < 0.50 的 12 只股票里，只有 2 只达到了 2x（比例仅 16.7%）——这两只是昆仑万维和万兴科技，属于情绪驱动涨幅，框架本身认为它们不值得建仓，只是市场用情绪把它们推到了 2x。

## 六、优化建议

### 建议 1：Regime 乘数纳入 MB-Score（高优先级）

**问题**：Regime 仅影响 MC 引擎，不影响入场决策。  
**修改**：在 MB-Score 末端乘以 Regime_mult：

```
Regime_mult: R1=1.00 | R2=0.97 | R3=0.88 | R4=强制归零
MB_Score = min(1.35, ... × Regime_mult)
```

**预期效果**：消除 R3 环境下的错误入场信号，3x F1 从 0.762 → 约 0.85+。

### 建议 2：SCP 权重提升至 24%（中优先级）

**问题**：SCP 在 2x 模式 S4 中仅占 15%，但区分力是 Moat 的 10 倍。  
**修改**：S4_2x 中 SCP 权重从 15% → 24%，相应压缩 Moat 和 OptionSpace 权重。

### 建议 3：P_eff > 25% 的附加条件（中优先级）

**问题**：P ∈ [25%, 55%] 的 2x 命中率仅 17%，但框架允许这一区间正常入场。  
**修改**：P > 25% 时要求同时满足 OpLeverage ≥ 1.5、催化等级 ≥ S 级、OV/MV ≥ 2.5，否则 MB ×0.88。

### 建议 4：概率校准表附加置信区间（低优先级）

**问题**：表中 "~100%" 表述缺乏置信区间，n=8 时 95% CI 宽达 ±20%。  
**修改**：每个概率值后注明 `(n=X, 95% CI: A%–B%)`。

### 建议 5：低 SCP × 高 S2 交叉检验（低优先级）

**问题**：S2 ≥ 0.80 但 SCP ≤ 0.40 的组合说明催化可能是情绪驱动。  
**修改**：此组合触发"催化剂可靠性复查"，要求 L2（资本支出锁定）≥ 0.70，否则 S2 × 0.90。

## 七、框架值得保留的部分

1. **PTS 保护机制**：8 个 3x 假阳性全有正收益，无一推荐亏损，说明 PTS 保护成功防止了"好逻辑被次矛盾过度打压"。

2. **论据驱动卖出的逻辑正确**：天齐锂业 2022 的 MB 从 0.91 自动降至 0.45，不需要额外判断，S2 恶化 + R4 Regime 的联合作用实现了"自动降温"。

3. **S2 的三层检测（L1/L2/L3）是核心创新**：有效区分了"真国产替代"（中微、长川、SCP≥0.80）和"伪国产替代"（龙芯 SCP=0.50 但 S1=0.38、景嘉微 SCP=0.45）。龙芯中科 P=8% 但 MB=0.464 被正确拒绝，核心原因正是 L1（物理瓶颈）不强。

4. **周期股自动识别能力**：未专门设计周期检测器，但通过 Regime + S2 强度 + P_eff 的联合作用，正确区分了同一公司在不同周期位置的表现（天齐锂业 2021 vs 2022）。

5. **Kelly f*/3 的仓位控制**：即使存在 25% 的 3x 假阳性率，这些假阳性全部有正收益，结合 f*/3 的建仓逻辑，实际资金损失风险极低。

## 八、结论

V18.2 框架在 78 只扩展样本上的核心表现：

- **2x 模式**：精确率 100%，召回率 88%，F1=0.938。没有推荐出任何最终亏损或未达标的标的。
- **3x 模式**：精确率 75%，但 8 个假阳性全部有正收益（+120%~+200%），无一真实亏损。框架真正的"危险"来自召回率不足——漏掉了 7 个真实多倍股，主要是低 SCP 的情绪驱动股和 Regime 不佳时依然涨起来的股票。

**最重要的单项发现是 Regime 信号**：R1/R2 下 2x 命中率 74–100%，R3 下仅 27%，R4 下 0%。这个信号没有进入 MB-Score，是框架当前最大的结构性漏洞，修复后预计整体精度提升 14pp 以上。
