## 三、为什么10%/月 + Sharpe>2 不可能同时实现

### 数学推导

```
Sharpe(年化) = (月均 / 月std) × √12

若同时满足: 月均 ≥ 10%, Sharpe_ann ≥ 2.0
则: 月std ≤ 10% × √12 / 2 = 17.3%

意味着月收益分布:
  95%置信区间 = [-24.6%, +44.6%]
  —— 即允许最大月亏损24.6%
```

这意味着"即使运气最差的月份也只亏24.6%", 同时每月平均赚10%。

**这需要策略在每个月都能持有快速上涨的股票, 几乎没有"空档期"。**

### 实际约束

1. **A股T+1制度**: 当天买入无法止损, 追高被套第二天才能出
2. **动量的本质**: 趋势股必然有大幅回调期 (这是创造趋势的代价)  
3. **月std无法低于约10%**: 单股动量策略的月度方差由个股波动决定
4. **换仓成本**: 每笔约0.13%的印花税+佣金, 频繁换仓侵蚀收益

### 与全球顶级策略对比

| 策略 | 年化收益 | Sharpe | 说明 |
|------|---------|--------|------|
| **本策略最优** | 41% | **1.09** | 单股动量, A股300只 |
| V8最优 (原报告) | 21% | 0.60 | 80只沪深300 |
| 文艺复兴大奖章 | 66% | ~2.0 | HFT+多策略, 非公开 |
| 桥水全天候 | ~10% | ~0.8 | 风险均衡, 杠杆 |
| **目标** | **214%** | **2.0** | **未有公开策略达到** |

## 四、实际可行的SOP

### 最优参数配置 (可实现)

```
┌─────────────────────────────────────────────────────┐
│  "龙头轮动" 最优参数                                    │
│                                                       │
│  宇宙: 300只A股 (中证500成分股, 流动性好的)              │
│                                                       │
│  选股 (每天收盘后):                                     │
│    1. 计算20日线性回归斜率, 标准化为%/天                 │
│    2. 计算R² (趋势拟合度)                               │
│    3. 趋势得分 = 斜率 × R²                              │
│    4. 筛选: R² ≥ 0.4, 斜率 ≥ 0.05%/天                  │
│    5. 选得分最高的股票                                  │
│                                                       │
│  入场: 次日开盘买入, 全仓一只股                           │
│                                                       │
│  止损 (次日开盘执行):                                   │
│    · 收盘价 < 15日均线 × 0.99 → 次日止损                │
│                                                       │
│  换仓 (次日开盘执行):                                   │
│    · 新最强股得分 > 当前持股得分 × 2.5 → 次日切换         │
│                                                       │
│  预期表现:                                             │
│    月均收益: 2-4%  (优秀时期可达5-8%)                    │
│    年化收益: 25-45%                                     │
│    年化Sharpe: 0.7-1.1                                 │
│    最大回撤: -40% ~ -65%                               │
└─────────────────────────────────────────────────────┘
```

### 分步操作流程

**Step 1: 数据准备 (每日收盘后)**
```
- 获取300只股票的日K线数据 (收盘价, 成交量)
- 推荐数据源: 同花顺iFind, 万得Wind, 或聚宽数据
```

**Step 2: 计算趋势得分**
```python
def trend_score(close_prices_20d):
    # 线性回归: 以时间为自变量, 价格为因变量
    x = range(20)
    slope, intercept, r, _, _ = scipy.stats.linregress(x, close_prices_20d)
    r2 = r ** 2
    slope_pct = slope / close_prices_20d.mean()  # 标准化
    if r2 < 0.4 or slope_pct < 0.0005:
        return 0  # 过滤
    return slope_pct * r2
```

**Step 3: 选股决策**
```
if 当前持仓得分 == 0 (无仓位):
    → 买入得分最高的股票

elif 最强股得分 > 当前持仓得分 × 2.5:
    → 次日开盘切仓至最强股

elif 收盘价 < 15日均线 × 0.99:
    → 次日开盘止损
    → 然后买入当时得分最高的股票
```

**Step 4: 风险控制**
```
- 不使用杠杆
- 永远满仓 (闲置资金产生机会成本)
- 最大仓位: 100% (单股)
- 止损后若无好信号可短暂空仓1-2天
```

## 六、如何进一步提升 (路线图)

### 可行方向 (预计效果)

1. **加入基本面过滤** → 胜率从46%→52%, 月均+0.5-1%
   - 过滤负增长、高负债企业
   - 优先选季报业绩超预期的
   
2. **加入板块轮动信号** → 减少错误切仓, 月均+0.5%
   - 识别当前热点板块
   - 在板块内部选最强个股
   
3. **优化入场时机** → 减少追高, 月均+0.3%
   - 在回调到20日均线附近时买入
   - 避免在涨幅已大时追入

4. **多股分散** → 降低回撤, Sharpe可能提升至1.3-1.5
   - 同时持有2-3只趋势最强的股票
   - 但月均会略有下降 (分散化)

### 不可行方向

- **月均10%**: 数学上需要月std<17.3%, 在单股策略中不可能
- **Sharpe>2**: 需要极高一致性, 全球仅Renaissance Medallion等HFT达到
- **杠杆放大**: 放大了收益也放大了亏损, Sharpe不变, 破产概率增加

## 八、一句话总结

> **原始SOP (5日线止损+随时切仓)** 在80只沪深300中: 月均-1.4%, 夏普-0.33, 实际亏损。
