### 7.1 三情景定义

> V18.2 的 MC 设计哲学：完整随机模拟（10,000 条路径）因信噪比过低，概率表不可靠。改为 3 情景 × 概率加权回答，概率表使用 48 只回测校准。

| 情景 | 描述 | 概率来源 | 触发条件 |
|:----:|------|----------|---------|
| **情景1：催化在轨** | 催化剂按预期兑现，渗透率持续提升，Regime 维持 R1/R2 | PTS（主矛盾强度），对标 S=0.85→P=85% | S2 催化未被证伪，p_falsify 未触发 |
| **情景2：催化延期** | 催化剂延迟但未取消，渗透率增速放缓，Regime 降至 R3 | p_falsify 未触发 × Regime 转移至 R3 概率 | S2 从 S/A 级降至 B 级，或领先指标转负 |
| **情景3：催化证伪** | 主矛盾被实质性破坏，渗透率停滞或下降，Regime R4/R5 | p_falsify 触发（约 0.8%-5%/季） | Type A/B 触发，或 MB 重估 < 0.70 |

                        price *= np.exp(-j_disappoint)
                        sigma += 0.08 * j_disappoint
                        sigma = max(p['sigma_floor'], sigma)
                        high_wm = max(high_wm, price)
                        dd = 1 - price/high_wm if high_wm > 0 else 0
                        max_dd = max(max_dd, dd)
                        continue

                regime = daily_regime[day]
                mu_t = mu_base + p['mu_flow'] + p['mu_P'] + self.mu_regime[regime]

                lam_up = self.lambda_up_func(day, p, catalyst_falsified) * self.jump_up_mult[regime]
                lam_down = p['lambda_down'] * self.jump_down_mult[regime]

                n_up = np.random.poisson(lam_up * dt)
                n_down = np.random.poisson(lam_down * dt)

                J_up = float(np.sum(genpareto.rvs(xi_eff, scale=0.25, size=n_up))) if n_up > 0 else 0.0
                J_down = float(np.sum(np.random.exponential(0.20, n_down))) if n_down > 0 else 0.0

                dW = np.random.normal() * np.sqrt(dt)
                dW_sigma = np.random.normal() * np.sqrt(dt)
                dZ = np.random.normal() * np.sqrt(dt)

                raw_ret = (mu_t - 0.5*sigma**2)*dt + sigma*dW + J_up - J_down

                daily_ret = np.clip(raw_ret, -0.20, 0.20)
                overflow += raw_ret - daily_ret
                if overflow > 0:
                    release = min(overflow * 0.6, 0.20 - daily_ret)
                    daily_ret += release
                    overflow -= release
                elif overflow < 0:
                    overflow *= 0.50
                    release = overflow * 0.3
                    daily_ret += release
                    overflow -= release

                S *= np.exp(daily_ret)

                sigma_new = sigma + 2.0*(sigma_long - sigma)*dt + 0.30*np.sqrt(max(sigma, p['sigma_floor']*0.5))*dW_sigma
                if n_up > 0: sigma_new += 0.04 * J_up
                if n_down > 0: sigma_new += 0.08 * J_down
                sigma = max(p['sigma_floor'], sigma_new)

                t_remain = max(0.01, 1.0 - day/252)
                moneyness = S / K if K > 0 else 999
                tv_mult = 0.25 if moneyness > 2.0 else (0.40 if moneyness > 1.0 else 0.55)
                time_value = S * sigma * np.sqrt(t_remain) * tv_mult
                intrinsic = max(S - K, 0)
                V = intrinsic + p['W_opt'] * time_value

                if M > 2.5: kM = 3.0
                elif gamma_moat_eff > 1.2: kM = 0.0
                else: kM = 0.5
                dM = kM*(1.0-M)*dt + 0.25*M*dZ + gamma_moat_eff*M*(0.5*J_up - 0.35*J_down)
                M = np.clip(M + dM, 0.40, 3.00)

                price = V * M * self.w_macro[regime]
                high_wm = max(high_wm, price)
                dd = 1 - price/high_wm if high_wm > 0 else 0
                max_dd = max(max_dd, dd)

                if price >= init_price * 2.0 and results['first_double_day'][i] == -1:
                    results['first_double_day'][i] = day
                if price >= init_price * 3.0 and results['first_triple_day'][i] == -1:
                    results['first_triple_day'][i] = day

            results['final_prices'][i] = price
            results['max_prices'][i] = high_wm
            results['max_drawdowns'][i] = max_dd

        return results

    def simulate_portfolio(self, stocks_params_list, regime_sequence, n_paths=2000):
        n_stocks = len(stocks_params_list)
        dt = self.dt
        daily_regime = np.repeat(regime_sequence, 21)[:self.n_days]

        sectors = list(set(sp.get('sector', '半导体') for sp in stocks_params_list))
        sector_idx = {s: i for i, s in enumerate(sectors)}
        n_sectors = len(sectors)

        corr_matrix = np.eye(n_sectors)
        for i, s1 in enumerate(sectors):
            for j, s2 in enumerate(sectors):
                if i != j:
                    corr_matrix[i, j] = self._get_sector_corr(s1, s2)
        L = np.linalg.cholesky(corr_matrix)

        all_final_prices = np.zeros((n_stocks, n_paths))
        all_max_prices = np.zeros((n_stocks, n_paths))

        for path_i in range(n_paths):
            R_market = np.zeros(self.n_days)
            for day in range(self.n_days):
                regime = daily_regime[day]
                R_market[day] = np.random.normal(
                    self.mu_market_daily[regime], self.sigma_market_daily[regime])

            R_sector = np.zeros((n_sectors, self.n_days))
            for day in range(self.n_days):
                z_indep = np.random.normal(size=n_sectors)
                z_corr = L @ z_indep
                for k in range(n_sectors):
                    R_sector[k, day] = (self.rho_sm * R_market[day] +
                                        np.sqrt(1 - self.rho_sm**2) * self.sigma_sector * z_corr[k])

            for stock_i, sp in enumerate(stocks_params_list):
                beta_m = sp.get('beta_market', 1.0)
                beta_s = sp.get('beta_sector', 0.8)
                sec = sp.get('sector', '半导体')
                sec_i = sector_idx[sec]
                sigma_idio = sp.get('sigma_idio', 0.25)

                init_price = sp['current_price']
                gamma_moat_eff = min(sp['gamma_moat'], 1.5) if sp['catalyst_type'] == 'trend' else sp['gamma_moat']
                sigma_long = max(sp['sigma_floor'], sp['sigma0'] * 0.55) + sp.get('sigma_moat_premium', 0.0)

                k_roll = np.random.random()
                if k_roll < 0.15: K = sp['K_base'] * 0.75
                elif k_roll < 0.40: K = sp['K_base'] * 0.90
                elif k_roll < 0.75: K = sp['K_base']
                elif k_roll < 0.90: K = sp['K_base'] * 1.25
                else: K = sp['K_base'] * 1.60

                S = sp['S0']
                M = 1.0
                sigma = sp['sigma0']
                overflow = 0.0
                price = init_price
                high_wm = init_price
                catalyst_falsified = False
                xi_eff = sp['xi_gpd']
                mu_base = sp['mu_base']
                p_falsify = sp.get('p_falsify', 0.0)
                quarter_days = {0, 63, 126, 189}

                for day in range(self.n_days):
                    if day in quarter_days and not catalyst_falsified and p_falsify > 0:
                        if np.random.random() < p_falsify:
                            catalyst_falsified = True
                            xi_eff = 0.0
                            mu_base -= 0.08
                            j_disappoint = np.random.exponential(0.30)
                            price *= np.exp(-j_disappoint)
                            sigma += 0.08 * j_disappoint
                            sigma = max(sp['sigma_floor'], sigma)
                            high_wm = max(high_wm, price)
                            continue

                    regime = daily_regime[day]
                    lam_up = self.lambda_up_func(day, sp, catalyst_falsified) * self.jump_up_mult[regime]
                    lam_down = sp['lambda_down'] * self.jump_down_mult[regime]

                    n_up = np.random.poisson(lam_up * dt)
                    n_down = np.random.poisson(lam_down * dt)
                    J_up = float(np.sum(genpareto.rvs(xi_eff, scale=0.25, size=n_up))) if n_up > 0 else 0.0
                    J_down = float(np.sum(np.random.exponential(0.20, n_down))) if n_down > 0 else 0.0

                    factor_ret = beta_m * R_market[day] + beta_s * R_sector[sec_i, day]
                    idio_ret = sigma_idio * np.sqrt(dt) * np.random.normal()
                    raw_ret = factor_ret + idio_ret + J_up - J_down

                    daily_ret = np.clip(raw_ret, -0.20, 0.20)
                    overflow += raw_ret - daily_ret
                    if overflow > 0:
                        release = min(overflow * 0.6, 0.20 - daily_ret)
                        daily_ret += release
                        overflow -= release
                    elif overflow < 0:
                        overflow *= 0.50
                        release = overflow * 0.3
                        daily_ret += release
                        overflow -= release

                    S *= np.exp(daily_ret)

                    dW_sigma = np.random.normal() * np.sqrt(dt)
                    sigma_new = sigma + 2.0*(sigma_long - sigma)*dt + 0.30*np.sqrt(max(sigma, sp['sigma_floor']*0.5))*dW_sigma
                    if n_up > 0: sigma_new += 0.04 * J_up
                    if n_down > 0: sigma_new += 0.08 * J_down
                    sigma = max(sp['sigma_floor'], sigma_new)

                    t_remain = max(0.01, 1.0 - day/252)
                    moneyness = S / K if K > 0 else 999
                    tv_mult = 0.25 if moneyness > 2.0 else (0.40 if moneyness > 1.0 else 0.55)
                    time_value = S * sigma * np.sqrt(t_remain) * tv_mult
                    intrinsic = max(S - K, 0)
                    V = intrinsic + sp['W_opt'] * time_value

                    dZ = np.random.normal() * np.sqrt(dt)
                    if M > 2.5: kM = 3.0
                    elif gamma_moat_eff > 1.2: kM = 0.0
                    else: kM = 0.5
                    dM = kM*(1.0-M)*dt + 0.25*M*dZ + gamma_moat_eff*M*(0.5*J_up - 0.35*J_down)
                    M = np.clip(M + dM, 0.40, 3.00)

                    price = V * M * self.w_macro[regime]
                    high_wm = max(high_wm, price)

                all_final_prices[stock_i, path_i] = price
                all_max_prices[stock_i, path_i] = high_wm

        return all_final_prices, all_max_prices

    def run(self):
        macro_paths = self.generate_macro_paths(10000)
        clusters = self.cluster_macro_paths(macro_paths, n_clusters=50)

        all_results = {
            'final_prices': [], 'max_prices': [], 'max_drawdowns': [],
            'first_double_day': [], 'first_triple_day': [], 'falsified': [],
        }

        for cluster in clusters:
            n_inner = max(100, int(100000 * cluster['freq']))
            inner = self.simulate_single(cluster['sequence'], n_paths=n_inner)
            for key in all_results:
                all_results[key].extend(inner[key].tolist())

        for key in all_results:
            all_results[key] = np.array(all_results[key])

        stats = self.compute_statistics(all_results)
        stats['kelly'] = self.compute_kelly(stats)
        return stats

    def run_portfolio(self, stocks_params_list):
        macro_paths = self.generate_macro_paths(10000)
        clusters = self.cluster_macro_paths(macro_paths, n_clusters=50)

        n_stocks = len(stocks_params_list)
        all_finals = []
        all_maxes = []

        for cluster in clusters:
            n_inner = max(50, int(100000 * cluster['freq']))
            finals, maxes = self.simulate_portfolio(stocks_params_list, cluster['sequence'], n_paths=n_inner)
            all_finals.append(finals)
            all_maxes.append(maxes)

        combined_finals = np.concatenate(all_finals, axis=1)
        combined_maxes = np.concatenate(all_maxes, axis=1)

        init_prices = np.array([sp['current_price'] for sp in stocks_params_list])
        returns = combined_finals / init_prices[:, None]

        prob_any_1_3x = float(np.mean(np.any(returns >= 1.3, axis=0)))
        prob_any_2x = float(np.mean(np.any(returns >= 2.0, axis=0)))
        prob_any_3x = float(np.mean(np.any(returns >= 3.0, axis=0)))
        prob_any_4x = float(np.mean(np.any(returns >= 4.0, axis=0)))
        prob_any_5x = float(np.mean(np.any(returns >= 5.0, axis=0)))
        prob_all_loss20 = float(np.mean(np.all(returns <= 0.8, axis=0)))

        indiv_probs_3x = [float(np.mean(returns[i] >= 3.0)) for i in range(n_stocks)]
        p_indep = 1 - np.prod([1 - p for p in indiv_probs_3x])
        div_ratio = prob_any_3x / p_indep if p_indep > 0 else 0

        return {
            'prob_any_1.3x': prob_any_1_3x,
            'prob_any_2x': prob_any_2x,
            'prob_any_3x': prob_any_3x,
            'prob_any_4x': prob_any_4x,
            'prob_any_5x': prob_any_5x,
            'prob_all_loss20': prob_all_loss20,
            'p_independent_any_3x': p_indep,
            'diversification_ratio': div_ratio,
            'individual_prob_3x': indiv_probs_3x,
        }

    def compute_kelly(self, stats):
        p = stats['prob_2x']
        avg_win = stats.get('mean_price', self.params['current_price'] * 2) / self.params['current_price'] - 1
        cvar = stats.get('cvar_95', -0.30)
        avg_loss = abs(cvar) if cvar < 0 else 0.25
        b = avg_win / avg_loss if avg_loss > 0 else 2.0
        q = 1 - p
        f_star = max(0, (p * b - q) / b)
        return {
            'f_star': f_star,
            'f_entry': f_star / 3,
            'f_confirm': f_star / 2,
            'f_full': f_star,
            'max_position': min(f_star, 0.25),
        }

    def compute_statistics(self, results):
        init = self.params['current_price']
        fp = results['final_prices']
        mp = results['max_prices']
        dd = results['max_drawdowns']
        returns = fp / init
        max_returns = mp / init

        stats = {
            'prob_1.3x': float(np.mean(returns >= 1.3)),
            'prob_1.5x': float(np.mean(returns >= 1.5)),
            'prob_2x': float(np.mean(returns >= 2.0)),
            'prob_3x': float(np.mean(returns >= 3.0)),
            'prob_4x': float(np.mean(returns >= 4.0)),
            'prob_5x': float(np.mean(returns >= 5.0)),
            'prob_10x': float(np.mean(returns >= 10.0)),
            'prob_intra_3x': float(np.mean(max_returns >= 3.0)),
            'prob_intra_2x': float(np.mean(max_returns >= 2.0)),
            'prob_loss_20': float(np.mean(returns <= 0.80)),
            'prob_loss_50': float(np.mean(returns <= 0.50)),
            'mean_price': float(np.mean(fp)),
            'median_price': float(np.median(fp)),
            'std_price': float(np.std(fp)),
            'pct_1': float(np.percentile(fp, 1)),
            'pct_5': float(np.percentile(fp, 5)),
            'pct_10': float(np.percentile(fp, 10)),
            'pct_25': float(np.percentile(fp, 25)),
            'pct_50': float(np.percentile(fp, 50)),
            'pct_75': float(np.percentile(fp, 75)),
            'pct_90': float(np.percentile(fp, 90)),
            'pct_95': float(np.percentile(fp, 95)),
            'pct_99': float(np.percentile(fp, 99)),
            'avg_max_drawdown': float(np.mean(dd)),
            'prob_dd_30': float(np.mean(dd > 0.30)),
            'prob_dd_50': float(np.mean(dd > 0.50)),
            'cvar_95': float(np.mean(fp[fp <= np.percentile(fp, 5)])) / init - 1,
            'avg_double_days': float(np.mean(results['first_double_day'][results['first_double_day'] > 0])) if np.any(results['first_double_day'] > 0) else -1,
            'avg_triple_days': float(np.mean(results['first_triple_day'][results['first_triple_day'] > 0])) if np.any(results['first_triple_day'] > 0) else -1,
            'prob_double_then_loss': float(np.mean((mp >= init*2) & (fp < init))),
            'falsified_rate': float(np.mean(results['falsified'])),
        }
        return stats

    def _get_sector_corr(self, s1, s2):
        if (s1, s2) in self.SECTOR_CORR:
            return self.SECTOR_CORR[(s1, s2)]
        if (s2, s1) in self.SECTOR_CORR:
            return self.SECTOR_CORR[(s2, s1)]
        return 0.20

## 第十一部分：不适用场景与核心局限

### 适用场景
- 产业渗透率1-55%的A股成长股
- 有明确催化剂的主题投资
- 组合策略（5-7只跨行业）的概率评估

### 不适用场景
- 纯价值/高股息标的
- ST/壳资源/重组概念
- 市值<30亿微盘股 / >5000亿超大盘
- 纯周期品（铜/锂/稀土等商品价格驱动型）

### 核心局限
1. 渗透率估计含3-5pct主观误差
2. 催化剂等级判定含主观成分
3. 马尔可夫转移矩阵基于历史，结构可能突变
4. β估计有时序不稳定性
5. GPD厚尾参数ξ对极端概率极度敏感
6. 不建模黑天鹅（战争/监管突变/造假暴雷）→ 由Type A硬性止损兜底
7. 极端行情下相关性突变至1.0（尾部相关性），组合分散效果低于模型预期
8. 月度检查依赖数据可得性，部分领先指标可能滞后
