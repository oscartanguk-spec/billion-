# V18.2 两倍模式补丁（2x Mode Patch）

**版本**：V18.2-2x
**基于**：V18.2完整Prompt（三倍模式）
**目标**：一年内股价翻倍（+100%）的高精确率选股
**设计日期**：2025-05-23

---

## 一、设计原则

### 1.1 为什么需要独立补丁？

| 维度 | 3x模式 | 2x模式 | 差异 |
|------|--------|--------|------|
| 目标收益 | +200% | +100% | 空间要求减半 |
| OV/MV要求 | ≥3才有高分 | ≥2即可 | OptionSpace评分标准不同 |
| 精确率预期 | 100%（回测） | **应≥100%**（目标更低→更容易实现） | 2x精确率必须≥3x |
| 选股池大小 | 3-7只 | 8-15只 | 2x候选更多 |
| 持有容忍度 | 允许高波动 | 中等波动即可 | 止盈逻辑不同 |
| 护城河要求 | AA级以上 | A级以上即可 | Moat门槛下调 |

### 1.2 补丁逻辑：覆盖而非重写

两倍模式 = V18.2框架 + 以下参数覆盖（override）。

未列出的部分（P0宏观状态机、P1动量、P2流动性、P4管理层、P7财务、P8客户集中度、论据驱动型卖出机制框架）**完全继承V18.2三倍模式，不做修改**。

## 二、参数覆盖表（2x Mode Overrides）

### 2.1 MB-Score阈值

| 参数 | 3x模式 | 2x模式 | 理由 |
|------|--------|--------|------|
| 入场硬门槛 | MB ≥ 0.80 | **MB ≥ 0.68** | 回测校准（见第五部分） |
| 强信号 | MB ≥ 0.95 | MB ≥ 0.82 | 比例下调 |
| 关注不建仓 | 0.75-0.79 | 0.62-0.67 | — |

### 2.2 S4 OptionSpace 映射表（核心变更）

**3x模式OV/MV映射（原）**：
```
>8→1.00 | 5-8→0.90 | 3-5→0.78 | 1.5-3→0.62 | 0.5-1.5→0.45 | <0.5→0.25
```

**2x模式OV/MV映射（新）**：
```
>5→1.00 | 3-5→0.92 | 2-3→0.82 | 1.5-2→0.68 | 1.0-1.5→0.50 | <1.0→0.25
```

关键差异：OV/MV=2.0在3x模式得0.62，在2x模式得**0.82**（+0.20）

**OV/MV计算方法不变**：终态合理市值（3-5年）/ 当前市值

### 2.3 S4 权重调整（含SCP引入）

**3x模式S4公式（原）**：
```
S4 = 0.35×Moat_Score + 0.30×OptionSpace + 0.20×TAM_Certainty + 0.15×EcoWidth
```

**2x模式S4公式（新）**：
```
S4 = 0.30×Moat_Score + 0.20×OptionSpace + 0.20×TAM_Certainty + 0.15×EcoWidth + 0.15×SCP_Score
```

变化逻辑：
- Moat权重下调（0.35→0.30）：2x不需要极深护城河
- OptionSpace权重下调（0.30→0.20）：空间要求本身就低，权重下降合理
- **新增SCP_Score（0.15）**：战略控制点——确定性加固维度

### 2.4 SCP_Score 评估维度（借鉴美股V18.3，A股适配）

```
SCP = 公司在产业链中占据的"不可绕过的瓶颈节点"

评分标准（A股适配版）：
  1.00: 行业标准制定者（掌握接口/协议/必要认证）
        例：中微公司（刻蚀设备认证壁垒→晶圆厂必须用）
  0.90: 产业链必经之路（无法绕过的瓶颈环节）
        例：中际旭创（800G光模块→AI集群必须有光互连）
  0.80: 技术瓶颈占据者（解决关键问题的唯一/极少方案）
        例：长川科技（先进SoC测试→芯片出厂必须测试）
  0.70: 国产替代唯一选择（政策驱动下的必选供应商）
        例：拓荆科技（CVD设备国产唯一选择）
  0.60: 客户深度嵌入（已进入核心供应链且替换成本极高）
        例：蓝特光学（苹果AR供应链认证完成）
  0.50: 有一定不可替代性但非唯一
        例：紫光国微（军工FPGA有备选但验证周期长）
  0.35: 差异化存在但竞对可快速追赶（12-18月）
  0.20: 无明确战略控制点（纯价格竞争/通用品）

SCP验证三问：
  Q1: 如果这家公司明天消失，下游客户是否立即陷入困境？（是→≥0.70）
  Q2: 竞对要达到同等地位需要多久？（>3年→≥0.80, 1-3年→0.60, <1年→0.35）
  Q3: 有没有替代技术路线可以绕过该环节？（无→+0.10, 有但不成熟→+0.05, 有且成熟→0）
```

### 2.5 P3 渗透率门槛放宽

| 参数 | 3x模式 | 2x模式 | 理由 |
|------|--------|--------|------|
| P3通过上限 | P≤55%（特殊条件可至70%） | **P≤70%（无条件）** | 2x不需要极大渗透空间 |
| S3映射 | P<15%→0.50 | P<25%→0.50 | 更宽松的"早期"定义 |

**2x模式S3映射表**：
```
P < 10%:  0.55（极早期，确定性偏低但空间大）
P = 10-25%: 0.50（甜蜜期，增速最快）
P = 25-45%: 0.58（加速期，量价齐升）
P = 45-65%: 0.45（成熟期前段，增速放缓）
P = 65-70%: 0.35（接近饱和）
P > 70%: 一票否决
```

注意：2x模式下S3在P=25-45%给出最高分（0.58），因为渗透率25-45%是量价齐升阶段，一年翻倍在此区间最常见。

### 2.6 P9-B 过热检验（放宽）

| 参数 | 3x模式 | 2x模式 | 理由 |
|------|--------|--------|------|
| 触发条件 | 6月涨幅>100% AND PEG>1.5 | 6月涨幅>**150%** AND PEG>**2.0** | 2x对估值容忍度更高 |
| 惩罚幅度 | ×0.92 | ×**0.94** | 惩罚减轻 |

逻辑：涨了150%的股票再涨100%（达到从低点2.5x→5x）才是"过热"。而涨了100%的股票再翻倍（达到4x）对2x目标而言并非不可能。

### 2.7 Moat准入门槛

| 参数 | 3x模式 | 2x模式 | 理由 |
|------|--------|--------|------|
| 最低Moat等级 | B+级（特殊条件） | **B级可通过**（SCP≥0.60时） | SCP补偿弱Moat |
| 一票否决 | C级 | C级（不变） | — |

新规则：Moat=B级 但 SCP≥0.60 → 允许通过（SCP作为确定性补偿）

### 2.8 Cat_Mult（类别乘数）

| 等级 | 3x模式 | 2x模式 |
|------|--------|--------|
| S+ | 1.15 | 1.12 |
| S | 1.10 | 1.08 |
| A+ | 1.05 | 1.04 |
| A | 1.00 | 1.00 |
| B+ | 0.95 | 0.96 |

2x模式下乘数区间收窄，因为目标本身更温和，不需要极端催化来驱动。

### 2.9 PTS机制调整

| 参数 | 3x模式 | 2x模式 |
|------|--------|--------|
| PTS公式 | 0.30×Cat + 0.25×Runway + 0.25×OptSpace + 0.20×Moat | 0.25×Cat + 0.25×Runway + 0.20×OptSpace + 0.15×Moat + **0.15×SCP** |
| ≥0.80 floor | 0.88 | 0.90 |
| [0.65,0.80) floor | 0.82 | 0.85 |
| [0.50,0.65) floor | 0.75 | 0.78 |
| <0.50 floor | 0 | 0 |

2x模式PTS保护更强（floor更高），因为2x对主矛盾的要求更容易满足，满足后应给予更强保护。

## 三、止盈/持有期管理（2x模式特有）

### 3.1 目标达成止盈

**3x模式**：无固定止盈目标（论据驱动持有）
**2x模式**：

```
达成+100%（即2x）后启动"锁定模式"：
  Step 1: 达到+100%时立即设置论据检查点
  Step 2: 诊断核心论据是否仍支持进一步上涨
    - 是 → 继续持有（自动升级为3x模式管理）
    - 否 → 卖出50%，剩余50%设trailing(-15%从最高点)
  Step 3: 达到+150%时重新诊断
    - 论据仍完整 → 全部转入3x模式
    - 论据部分受损 → 全部卖出锁定利润
```

### 3.2 Type R诊断调整

| 回撤幅度 | 3x模式 | 2x模式 |
|----------|--------|--------|
| -10% | — | 72小时诊断（2x模式更敏感） |
| -15% | 72小时诊断 | 48小时全面DA |
| -25% | 48小时DA | **24小时极端诊断** |
| -35% | — | 强制半仓 |
| -50% | 强制半仓 | 强制清仓 |

逻辑：2x目标更低→对回撤容忍度更低→诊断触发更早。

## 四、2x模式 MB-Score 完整计算公式

```
S4_2x = 0.30×Moat_Score + 0.20×OptionSpace_2x + 0.20×TAM_Certainty + 0.15×EcoWidth + 0.15×SCP_Score

Linear_2x = S1×0.22 + S2×0.22 + S3_2x×0.22 + S4_2x×0.22 + 0.12×√(S2 × S4_2x)

MB_raw_2x = Linear_2x + P1_accel（+0.03 if applicable）

PTS_2x = 0.25×Catalyst + 0.25×Runway + 0.20×OptionSpace + 0.15×Moat + 0.15×SCP

Secondary_floor_2x = {PTS≥0.80: 0.90, [0.65,0.80): 0.85, [0.50,0.65): 0.78, <0.50: 0}

Secondary_Mult_2x = max(Secondary_floor_2x, Crowd_Disc × P2_largecap × P9_adj × P9B_2x_overheat)

MB_Score_2x = min(1.35, MB_raw_2x × Resonance × Cat_Mult_2x × Secondary_Mult_2x × P8_adj)

入场门槛：MB_Score_2x ≥ 0.68
```
