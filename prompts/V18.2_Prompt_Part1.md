## 设计哲学：主次矛盾分层原则

### 核心认知

三倍股的本质 = **不可逆的结构性趋势 × 足够的价值空间**。这是主矛盾。
资金流向、估值波动、短期情绪是次矛盾——它们影响路径和时机，但不决定终局。

**框架推论**：
- 如果主矛盾足够强（趋势不可逆+空间巨大+护城河完整），次矛盾的短期波动（ETF调仓、融资余额、PE分位偏高）不应具有一票否决的权力
- 如果主矛盾本身就弱（趋势可逆/空间有限/护城河脆弱），次矛盾的杀伤力应完全释放

### 因子分类

| 层级 | 属性 | 具体因子 | 作用 |
|------|------|----------|------|
| **主矛盾** | 结构性·不可逆 | S2催化剂强度、P3渗透率跑道、S4期权空间(OV/MV)、P6护城河 | 决定"能否3x" |
| **次矛盾** | 时机性·可逆 | S3估值、P7拥挤度、P9机构动向、P2资金流入、P9B过热 | 决定"何时买/买多少" |
| **物理硬约束** | 不可克服 | 市值>5000亿、市值<30亿、成交额不足、Regime R5、P8核心人员流失>15% | 一票否决（不受PTS保护） |

### PTS (Primary Thesis Score) 量化机制

```
PTS = 0.30×Catalyst_Strength + 0.25×Runway + 0.25×OptionSpace + 0.20×Moat

Catalyst_Strength (来自S2的Intensity判定):
  S+(>0.9): 1.00 | S(0.7-0.9): 0.85 | A(0.5-0.7): 0.60 | B(0.3-0.5): 0.35 | C(<0.3): 0.10

Runway (来自P_eff):
  P_eff < 10%: 1.00 | 10-20%: 0.85 | 20-35%: 0.65 | 35-55%: 0.40 | >55%: 0.15

OptionSpace (来自OV/MV):

**OV/MV 定义：**
```
OV（期权价值）= SOTP（现有业务线终态）+ Σ 已验证新市场期权价值
MV（当前市值）= 股价 × 总股本
OV/MV = (SOTP + Options) / MV
```

**SOTP 部分：** 按实际业务线拆分，每条线独立估算终态营收×净利率×合理PE，逐线加总。

**Options 部分：** 新市场期权价值，必须通过以下三条件测试：
  □ 条件①：技术可复用（现有技术/专利/工艺可覆盖该新市场）
  □ 条件②：需求已验证（有实际营收>总收入5%, 或正式合同, 或通过客户量产验证）
  □ 条件③：不可替代性（在新市场中 SCP ≥ 0.50）

  三条件全满足 → 全额计入 OV，上限 Options 总值不超过 SOTP 的 50%
  任一条件不满足 → 不计入 OV

**OV/MV ≈ 1.5-3 评分：**
  >8: 1.00 | 5-8: 0.90 | 3-5: 0.75 | 1.5-3: 0.55 | 0.5-1.5: 0.30 | <0.5: 0.10

Moat (来自P6等级):
  AAA: 1.00 | AA: 0.85 | A: 0.70 | B: 0.50 | C: 0.25
```

### PTS保护机制（次矛盾杀伤力上限）

```
次矛盾合计折扣 = Crowd_Disc × P2_largecap × P9_adj × P9B_overheat × S3_penalty_factor

折扣下限(floor)由PTS决定:
  PTS ≥ 0.80: 次矛盾折扣floor = 0.88（最多打88折，不可更低）
  PTS ∈ [0.65, 0.80): 次矛盾折扣floor = 0.82
  PTS ∈ [0.50, 0.65): 次矛盾折扣floor = 0.75
  PTS < 0.50: 无保护（次矛盾完全释放）

实际应用:
  Secondary_Mult = max(floor, Crowd_Disc × P2_largecap × P9_adj × P9B_overheat)
```

**设计意图**：
- PTS=0.85的股票（如：S+催化+P<10%+OV/MV>5+AA护城河），即使同时遭遇拥挤+过热+ETF减仓，MB最多被打88折，不会被杀到阈值以下
- PTS=0.45的股票（如：A级催化+P>40%+OV/MV<2+B级护城河），次矛盾的每一个负面信号都会充分体现，精确率不受损

### 一票否决保留清单（不受PTS保护）

以下条件触发时，无论PTS多高都直接排除：
1. 市值 > 5000亿 或 < 30亿
2. 日均成交额不达标
3. Regime = R5（系统性危机）
4. P8 核心技术人员离职率 > 15%
5. P6 Moat = C级 且 不满足C级通过的特殊条件
6. P3 趋势已证伪（渗透率连续2季绝对下降，非"高位停滞"）

注意：P3的**高位停滞**（P>55%但未下降）和**大市值附加条件**不再是一票否决，而是通过PTS保护机制处理。

### P3上界松绑规则

原规则：P ∈ [1%, 55%] 硬性区间。

修正后：
```
P ∈ [1%, 55%]: 正常通过
P ∈ (55%, 70%] 且 满足以下任一:
  (a) 公司有已验证的第二增长曲线，贡献增速>20%且营收占比>15%
  (b) P_eff（价值量修正后）< 35%
  → 通过P3，但Runway评分使用实际P（得分较低，自然拉低PTS）

P > 70% 或 (P>55% 且无二次曲线 且 P_eff无修正): 
  → P3不通过（主矛盾本身失败）
```

**大市值（2000-5000亿）三条件评估机制**：

三条件定义：
```
C1: 主动资金流入确认
C2: 催化剂≥S级
C3: P_eff < 25%
```

**C1 主动资金流入确认（替代原"ETF增速Top5%"）**：

区分被动调仓与主动流入：
| 资金类型 | 计入C1判定 | 不计入C1 |
|----------|-----------|---------|
| 主动型基金季度加仓>3pct | ✓ | |
| 行业/主题ETF持仓增加 | ✓ | |
| 北向资金季度净增>10% | ✓ | |
| 宽基指数ETF（沪深300/创业板ETF等）权重调整 | | ✗（被动再平衡） |
| 融资余额增长（杠杆资金） | | ✗（不代表机构认可） |

C1通过条件：上述"计入"项中**任一**满足。

**C2 催化剂≥S级**：
- S+或S(高密/标准)均通过
- A级及以下不通过

**C3 有效渗透率P_eff < 25%（替代原"P<15%"）**：

P_eff的计算区分两种增长模式：

| 增长模式 | P_eff定义 | 适用场景 |
|----------|-----------|---------|
| **纯量驱动型** | P_eff = P_quantity | 传统渗透（国产替代/新技术替代旧技术） |
| **价值量驱动型** | P_eff = P_quantity × (ASP_current / ASP_terminal) | 每代产品价值量倍增，即使渗透率已高但TAM仍在扩张 |

价值量驱动型判定条件（必须同时满足）：
1. 下一代产品单位价值量 > 当代 ×1.5
2. 产品迭代周期 ≤ 2年
3. 公司已获得下一代产品验证/订单

示例：
- 胜宏科技(PCB)：AI server PCB渗透率P_quantity≈18%，但Rubin PCB用量是Blackwell的3.33倍（+233%），P_eff = 18% × (1/3.33) ≈ 5.4%
- 澜起科技(DDR5接口)：DDR5渗透率65%，但DDR5→DDR6迁移周期>3年，不满足条件2 → 仍用P_quantity=65%

**三条件评分与处理**：

| 满足条件数 | 处理 | P2_largecap乘数 |
|-----------|------|----------------|
| 3/3全满足 | 正常通过 | ×1.00 |
| 2/3满足（含C2） | 通过，轻折扣 | ×0.95 |
| 2/3满足（不含C2） | 通过，中折扣 | ×0.90 |
| 1/3满足 | 通过，重折扣 | ×0.85 |
| 0/3满足 | 通过，极重折扣 | ×0.80 |

注意：
- P2_largecap属于"次矛盾"因子，受PTS保护机制约束（Secondary_floor）
- 即使0/3满足，只要PTS≥0.80，Secondary_Mult会被floor限制在0.88，不会被一票否决
- 大市值股票的真正否决只有物理硬约束（>5000亿）

#### P3 产业渗透率

**核心区间**：P_eff ∈ [1%, 55%] 正常通过

### 1.4 核心假设验证（5-Step Cross-Check Protocol）

> **定位**：P1-P9 数据收集完成后 → S1-S4 评分开始前。
> **目的**：在定量假设进入评分系统之前，做一次逻辑自检，避免线性外推错误。

**Step 1：关键假设提取**
识别本报告中最核心的 1-2 个定量假设——通常是驱动 MB-Score 的最关键输入：
- 营收/利润增速假设（S1 的 SUE/RevAccel）
- 渗透率假设（P3 的 P_eff/Runway）
- 终态空间假设（S4 的 OV/MV）
- 定价权假设（S4 的 Moat 或 S2 的催化强度）

**Step 2：物理/数学约束检查**
用最简单的数学验证假设是否自洽：
- 数学："Blended ASP = 旧占比×旧ASP + 新占比×新ASP"——新旧ASP此消彼长时，Blended ASP能否达到假设值？
- 物理："渗透率从A到B"——实现这个速度需要什么样的产业链配合？
- 常识："行业增速X%"——历史上有先例吗？最多能持续多久？

> **公式速查（常见定量假设的数学验证）**
> ```
> 营收增长 = 量增 × 价增（非加法，是乘法！）
> 量增 ≠ 景气——分拆为：行业增速 + 份额变化
> 价增 ≠ 定价权——要考虑：新品首发溢价 × 时间衰减
> Blended ASP = Σ(各产品占比 × 各产品ASP)——超过旧品降价幅度才算价增
> ```

**Step 3：对立面测试**
主动问："如果这个假设是错的，最可能往哪个方向偏——更乐观还是更悲观？幅度多大？"
- 如果偏悲观→MB本已不高（<0.70），结论基本不受影响：稳健
- 如果偏乐观→MB刚好在阈值附近（0.65-0.75），结论会翻转：需要警惕

**Step 4：博弈论交叉检查**
- 供需两侧是否都有议价权？我的推理是否只考虑了供方视角？
- 如果卖方是寡头，买方是否是集中采购的寡头（双边寡头）？
- 定价权是静态的（结构性的）还是动态的（需要不断续费的）？

**Step 5：结论稳健性测试**
"如果这个假设修正 20%（偏向悲观方向），MB 会变多少？结论会翻转吗？"
- 若 MB 变化 < 0.05：假设对结论无决定性影响 → 通过
- 若 MB 变化 > 0.10：假设是 MB 的敏感性因子 → 报告中应标注"高敏感度假设"
- 若 MB 变化后结论翻转（从推荐变为不推荐，或反之）：该假设必须附加数据来源验证，否则报告不计入正式记录

**5-Step 全部通过 → 继续进入 S1-S4 评分**
**任一 Step 未通过 → 调整假设后重新验证，或标注"高敏感度假设"进入 S1-S4**

### 2.1b 定价分区判定（Pricing Zone）

> W_opt 告诉你市场按什么逻辑给这只股票定价。不同的定价逻辑对应不同的风险属性、持有期特征和 MB 解读方式。

**三区定义：**

| 分区 | P_eff | W_opt | 定价逻辑 | 估值弹性 |
|:----|:-----:|:-----:|:--------|:--------|
| 🟢 **期权区** | < 15% | > 0.77 | 市场按「故事能讲多大」定价 | PE 容忍度高（60-200x），涨跌主要看催化密度 |
| 🟡 **切换区** | 15-30% | 0.21-0.77 | 市场在「故事」和「利润」之间摇摆 | PE 容忍度快速下降，利润增速越重要 |
| 🔵 **现金区** | > 30% | < 0.21 | 市场按「利润增长了多少」定价 | PE 决定涨跌，利润增速几乎等于股价增速 |

**为什么切换区最危险：**

```
同一个渗透率提升幅度，在不同区的后果完全不同：

  P 从 12% 到 24%（渗透率翻倍）：
    W_opt 从 0.84 降到 0.42 → 期权部分腰斩
    如果利润增速没跟上 P 的提升：
      PE 从 60x 杀到 30x（-50%）
      利润增长 +50%
      股价 = (+50%) × (-50%) = -25%
    → 渗透率翻倍了，股价跌了。这就是切换区的杀伤。

  而同期如果 P 从 35% 到 45%（也在翻渗透率）：
    W_opt 从 0.10 降到 0.04 → 几乎没有期权压缩
    股价涨跌几乎完全由利润增速决定
```

**三区 MB 解读指南：**

```
MB≥0.80 在三个区的含义完全不同：

  期权区（P<15%, W_opt>0.77）：
    MB≥0.80 = 「这个故事有足够的证据支撑」
    → 风险不在估值（市场不在乎 PE），在「故事是否持续被验证」
    → 首要监控：催化密度和领先指标

  切换区（P 15-30%, W_opt 0.21-0.77）：
    MB≥0.80 = 「利润增速撑得住 W_opt 下降的速率」
    → 风险在增速匹配——W_opt 每年自动下降约 3-6%，
      利润增速必须超过这个值，否则估值压缩吃掉所有涨幅
    → 首要监控：RevAccel 和 OpLeverage

  现金区（P>30%, W_opt<0.21）：
    MB≥0.80 = 「利润增速足够快到撑起一个合理的 PE」
    → 风险在 PE 分位——这个位置几乎所有的误差都来自估值代价（S3）
    → 首要监控：PE 分位和 FCF_Y
```

**实操判定流程：**

```
P_eff 计算完成 → 代入 W_opt 公式 → 查区 → 按区重新审视 MB

示例——神工股份（688233）：
  P_eff ≈ 18%
  W_opt(18) = 1/(1+exp((18-22)/6)) = 1/(1+exp(-0.667)) = 0.66
  → 切换区（P 15-30%, W_opt 0.21-0.77）
  → 市场仍在按期权定价（66% 想象空间）
  → 但营收增速只有 +6.2% → 切换区最危险的情况
  → 结论：要么营收加速到 >20% 填补估值，要么 PE 压缩吃掉其余

示例——长川科技（300604）：
  P_eff ≈ 12%
  W_opt(12) = 0.84 → 期权区
  → 市场按故事定价
  → 营收增速 +65% → 期权区最理想的情况：故事大 + 正在兑现
  → 所以 MB=0.98 是合理的
```

> **注意：** 定价分区不改变 MB 的计算公式和阈值。它改变的是**读 MB 的方式**——同一个 MB=0.75，在期权区意味着「故事够大但要看兑现速度」，在现金区意味着「利润增速够但空间有限」。两者的操作建议（建仓/不建仓）一样，但监控重点不同。

| **L2 资本支出锁定**（充分证据） | 是否有≥2家下游头部客户将该公司产品列入**已落地的、不可撤销的长期预算**中？ | ≥2家写入3年期CapEx预算 → 1.0<br>1家头部客户纳入长期采购 → 0.7<br>仅短期订单/年度合同 → 0.4<br>有意向书但无落地预算 → 0.1<br>无 → 0.0 |
| **L3 用户锁定强度**（持续性） | 一旦采用该技术/产品，用户能回退吗？切换成本多高？ | 物理锁定（已装机/已量产）→ 1.0<br>可回退但成本极高（>6月迁移）→ 0.6<br>可回退但需1-3月 → 0.3<br>随时可换（标准品）→ 0.0 |

**计算方式：**
```
Intensity_Score = 0.40×L1 + 0.35×L2 + 0.25×L3
  权重分配：L1最重要（必要条件）, L2是客观证据, L3是持续性放大

→ 映射为强度等级：
  ≥ 0.80 → 极高（S+）→ 1.00
  ≥ 0.60 → 高（S）→ 0.85
  ≥ 0.40 → 中（A）→ 0.73
  ≥ 0.20 → 低（B）→ 0.50
  < 0.20 → 极低（C）→ 0.25
```

> **示例——中微公司（刻蚀设备）：**
> L1=1.0（没有刻蚀机芯片造不出来）
> L2=0.7（中芯/长存持续扩产采购，但客户分散非2-3家寡头）
> L3=1.0（刻蚀机装机后锁定在产线全生命周期）
> Intensity = 0.40×1.0 + 0.35×0.7 + 0.25×1.0 = 0.40+0.245+0.25 = 0.895 → S+级 → 1.00
> 密度密度按季频取 0.70 → S2 = 1.00 × (0.80+0.20×0.70) = 0.94

> **示例——低空经济概念股：**
> L1=0.3（无人机不是必须、有多种替代）
> L2=0.1（无头部客户实质预算）
> L3=0.0（标准连接器，随时可换）
> Intensity = 0.40×0.3 + 0.35×0.1 + 0.25×0.0 = 0.155 → C级 → 0.25

Density_Factor:
  极高(月频): 1.00 | 高(双月频): 0.85 | 中(季频): 0.70 | 低(半年频): 0.50 | 极低(年频): 0.25

密度加分: 近6月≥3个独立催化事件 → S2+0.05 (cap at 1.00)
```

### 3.4 S3 估值安全边际

```
P<15%: S3=0.50 (中性)
15-25%: S3=0.30×PEG + 0.30×PE_pct + 0.40×FCF_Y
P≥25%: S3=0.20×PEG + 0.25×PE_pct + 0.55×FCF_Y
```

| 指标 | 评分 |
|------|------|
| PEG | <0.6→1.00 \| 0.6-1.0→0.80 \| 1.0-1.5→0.60 \| 1.5-2.5→0.40 \| >2.5→0.20 |

> **⚠️ PEG 计算口径规则**：
> 禁止混用。优先使用 Forward PE / Forward EPS CAGR（3-5年一致预期）;
> 若 Forward Growth 不可得 → 使用 TTM PE / Trailing Revenue Growth;
> 禁止 Forward PE / Trailing Revenue Growth 或 TTM PE / Forward Growth 的混用。
> 虽在极端值（>2.5）时结果不变，但口径一致性是量化框架的基本纪律。

| PE分位(5年) | <20%→1.00 \| 20-40%→0.75 \| 40-60%→0.50 \| 60-80%→0.30 \| >80%→0.15 |
| FCF_Y | >6%→1.00 \| 4-6%→0.82 \| 2-4%→0.60 \| 0-2%→0.40 \| <0→0.20 |

### 3.5 S4 不可复制性 + 期权空间 + TAM确定性

```
S4 = 0.35×Moat_Score + 0.30×OptionSpace + 0.20×TAM_Certainty + 0.15×EcoWidth

Moat_Score: AAA=1.00 | AA=0.85 | A=0.70 | B=0.50 | C=0.25

OptionSpace (OV/MV):
  >8→1.00 | 5-8→0.90 | 3-5→0.78 | 1.5-3→0.62 | 0.5-1.5→0.45 | <0.5→0.25
  生态位乘数: 若存在已验证的第二增长曲线 → OV/MV×1.3再评分

> **⚠️ 强制规则：OV/MV 计算规则**
>
> **第一部分：SOTP（现有业务线终态）**
> 按实际业务线拆分，每条线独立估算，逐线加总。每条线的增速必须有源（行业报告>公司指引>历史 CAGR）。
> 加权增长率 = Σ(各业务线占比 × 各业务线增速)——必须披露。
>
> **第二部分：Options（新市场期权估值）**
> 考察公司是否可进入新市场，且新市场是否具备期权价值。每个潜在新市场必须通过以下三条件测试才能计入 OV：
>
> | 条件 | 要求 | 通过标准 |
> |:----|:-----|:--------|
> | ① 技术可复用 | 现有技术/专利/工艺可覆盖该新市场 | ✅ 物理/工程上可行 |
> | ② 需求已验证 | 该新市场已有实际营收 > 总营收 5%，或有正式合同/量产验证 | ✅ 有实质性业务进展，不是「未来可能有机会」 |
> | ③ 不可替代性 | 在该新市场中 SCP ≥ 0.50 | ✅ 该市场中竞对无法通过简单降价、换供应商替代 |
>
> — 三条件全满足 → 全额计入 OV，Options 总值 ≤ SOTP 的 50%
> — 任一条件不满足 → 不计入 OV（不管是概念多好、市场多大——无证据不加分）
>
> **决策辅助（如何读 OV/MV 结果）：**
> | OV/MV | 含义 | 操作 |
> |:----:|:-----|:-----|
> | > 1.5 | 当前市值还未反映终态期权价值，空间大 | 正向驱动 MB |
> | 1.0-1.5 | 市值已接近终态，空间一般 | 中性影响 |
> | < 1.0 | 市值已超过终态期权价值，空间被透支 | 负向驱动 MB |
>
> **违背此规则的 OV/MV 值视为无效，报告不计入正式记录。**

TAM_Certainty:
  多机构量化确认: 1.00 | 合理估计: 0.70 | 仅概念: 0.35

EcoWidth:
  核心技术可复用到≥3个大市场: 1.00 | 1-2个相邻市场: 0.70 | 单一市场: 0.40

  ⚠️ 周期性折扣:
  若属强周期行业（锂矿/稀土/钢铁/航运/化工大宗）:
    EcoWidth_final = EcoWidth × 0.55
```

> ⚠️ **量化纪律：禁止主观平滑（§3.5a）**
>
> S1-S4 各子因子得分必须严格按公式精确计算。
> 计算精确到小数点后三位，四舍五入到小数点后两位仅允许作为最终显示格式。
>
> 禁止以下操作：
>  □ 因「为缩小争议」而取中位数/平均值
>  □ 因「数据有分歧」而向上/下调整分数
>  □ 在未改变底层数据假设的前提下，直接修改公式输出值
>
> 唯一允许的纠偏路径：
>  重新核查底层数据假设 → 若假设有误则重新计算 → 输出新分数。
>  不能绕过公式直接改分。
>
> **交叉引用：** 本规则覆盖 S1（§3.2）、S2（§3.3）、S3（§3.4）、S4（§3.5）共计四个评分模块。

## 第五部分：卖出决策SOP（论据驱动型·V18.2升级）

### 5.0 设计哲学

```
price = V × M × w_macro

V = 期权价值（内在价值 + 时间价值）→ 由主矛盾决定（渗透率/催化/护城河/空间）
M = 情绪乘数 ∈ [0.40, 3.00]        → 市场情绪波动，短期不可预测
w_macro = 宏观系数                   → Regime决定，系统性因素
```

**核心原则**：
- **V下降 → 卖出**（论据失效，期权价值本身缩水）
- **M下降 → 不卖**（情绪波动，主矛盾未变）
- **w_macro下降 → 减仓不清仓**（系统性风险，但公司本身没问题）
- **无法判断V/M/w → 触发强制诊断**（72小时内必须完成归因）

**价格下跌≠卖出信号。价格下跌=强制诊断信号。**

### 5.1 卖出决策完整框架

```
┌─────────────────────────────────────────────────────────────────┐
│                V18.2 论据驱动型卖出决策体系                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Type A: 物理硬约束（不可逆事件，立即执行）                        │
│  Type B: 主矛盾证伪（V下降确认，主动退出）                        │
│  Type C: 三级降级（月检驱动，渐进响应）                           │
│  Type D: 止盈/再平衡（盈利管理）                                  │
│  Type R: 回撤诊断（价格触发→归因→条件响应）← 替代旧trailing stop  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 Type A: 物理硬约束（立即执行，无需诊断）

仅限**不可能是M波动**的事件——这些事件直接摧毁V本身：

| # | 条件 | 执行速度 | 归因 |
|---|------|---------|------|
| A1 | 公司被立案调查/财务造假曝光 | 当日/次日清仓 | V→0（信用消失） |
| A2 | 核心催化剂被100%证伪（临床失败/大客户取消/政策180°反转） | 3日内清仓 | V骤降（催化灭失） |
| A3 | 核心技术人员离职率单季>15% | 5日内清仓 | V缓慢归零（护城河瓦解） |
| A4 | Regime从R1/R2直接跳至R5 | 5日内全部持仓清至50% | w_macro断崖（系统性危机） |

**注意**：旧A1（连续跌停）和旧A3（管理层离职）从Type A移除——它们可能是M波动，需先诊断。
**注意**：旧A5（回撤>35%+MA120↓）从Type A移除→并入新Type R诊断机制。

**执行纪律**：Type A触发后**不允许**"再等等看"。先退出，后续有机会再买回。

### 5.3 Type B: 主矛盾证伪卖出（V确认下降）

当DA检查或领先指标确认**主矛盾本身失败**：

| 主矛盾 | 证伪信号 | 确认标准 | 动作 |
|--------|---------|---------|------|
| 趋势不可逆(P3) | 渗透率连续2季绝对停滞或下降 | 非季节性波动，有2个独立数据源 | 清仓 |
| 趋势不可逆(P3) | 确定性技术替代已量产 | 替代品性能>1.5x且成本<0.8x | 清仓 |
| 护城河完整(P6) | 竞对量产+抢份额（市占率↓>5pct连续2季） | 非一次性订单分流 | 清仓 |
| 催化剂有效(S2) | 催化强度从S/S+降至B/C | 领先指标证实需求增速<行业平均 | 减至f*/4，1季观察 |
| 盈利在加速(S1) | 连续2季miss（实际<一致预期×85%） | 非一次性因素（汇兑/减值） | 减至f*/4，下季再miss则清仓 |

**与Type A的区别**：Type B需要**确认时间**（至少1-2周的证据积累），不是一瞬间的事件。

### 5.4 Type C: 三级降级系统（月检驱动）

来自月度检查清单（Section 6.1）的降级响应：

| 级别 | 触发 | 动作 | 仓位 | 时间窗口 |
|------|------|------|------|---------|
| **Level 1 黄灯** | 月检黄色≥4项 OR 1个领先指标转负 | 标注"观察期" | 减至f*/3 | 30日deadline |
| **Level 2 橙灯** | 月检红色=1项 OR ≥2个领先指标转负 OR MB重估<0.75 | 执行减仓 | 减至初始仓位50% | 10日内 |
| **Level 3 红灯** | 月检红色≥2项 OR DA-Total<0.60 OR MB重估<0.70 | 清仓 | → 0% | 5日内 |

**降级恢复规则**：
- Level 1→恢复：下月月检回到黄色≤2项 + MB重估≥0.82 → 取消观察期
- Level 2→恢复：连续2月月检全绿 + MB重估≥0.85 + 催化剂新验证 → 可加回仓位
- Level 3：不恢复（已清仓），如需重新建仓按全新标的流程走

### 5.5 Type D: 止盈/再平衡

| 条件 | 动作 | 逻辑 |
|------|------|------|
| 单只仓位因涨幅>35% | 减仓至25% | 单一标的风险暴露控制 |
| 组合年化收益已达+100% | 评估是否整体减仓20% | 锁定利润 |
| 涨幅达+300%且PEG>2.5 | 减仓50% | 赔率已大幅下降 |
| 涨幅达+500% | 减仓至25% | 持有远期call |

### 5.6 Type R: 回撤诊断机制（替代旧trailing stop）

**核心理念**：价格回撤不是卖出信号，而是**强制诊断信号**。诊断结果决定行动。

#### 5.6.1 诊断触发阈值

| 回撤幅度（从持仓期高点） | 触发动作 | 诊断时限 |
|------------------------|---------|---------|
| -15% | **一级诊断**：启动V/M/w归因 | 72小时 |
| -25% | **二级诊断**：完整DA重做 + MB重估 | 48小时 |
| -40% | **三级诊断**：极端情景评估 | 24小时 |
| -50% | **资本保护线**：无条件减半仓，剩余等诊断 | 立即减半 |

#### 5.6.2 V/M/w_macro 归因诊断协议

触发后72小时内必须完成以下诊断：

```
┌─────────────────────────────────────────────────────────────────┐
│              回撤归因诊断流程（72小时协议）                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  第一步：排除V下降（检查主矛盾完整性）                            │
│    □ 营收增速是否出现新的负面数据（YoY转负/连续2季减缓）？        │
│    □ 利润增速是否大幅下滑（>50%降幅）？                           │
│    □ 研发投入是否被大幅削减（>20%降幅）？← 最重要单一指标         │
│    □ 毛利率是否崩塌式下滑（>10pct）？                             │
│    □ 催化剂是否延期/取消/弱化？                                   │
│    □ 护城河是否被突破（竞对新进展/客户流失）？                     │
│    □ 行业同行是否也集体下滑？← 区分个股vs行业的关键                │
│    □ 是否有未公开的利空（研报下调/产业链传闻/媒体报道）？           │
│                                                                  │
│    → 任一项为"是" → 归因为V下降 → 进入5.6.3 V下降响应             │
│    → 全部为"否" → 继续第二步                                      │
│                                                                  │
│  第二步：判断w_macro（系统性因素）                                 │
│    □ 大盘同期跌幅是否>10%？                                       │
│    □ 行业指数同期跌幅是否>15%？                                   │
│    □ Regime是否恶化（R1/R2→R3/R4）？                              │
│    □ 是否有宏观政策突变（加息/制裁/流动性收紧）？                  │
│                                                                  │
│    → 满足≥2项 → 进入 2.5 层：区分真/假 w_macro                   │
│    → 不满足 → 继续第三步                                          │
│                                                                  │
│  2.5 层：真假 w_macro 甄别（资金面 vs 基本面）                    │
│    回测数据（2019-2024年8次危机）：如果满足以下≥2项，归因为        │
│    「假 w_macro」（纯资金面驱动），跳转至第三步 M下降处理：         │
│      □ 融资余额 5 日内降幅 > 15%（杠杆资金被迫平仓）              │
│      □ 行业/主题 ETF 连续 3 日净赎回 > 10% 份额                   │
│      □ 跌幅集中在中小盘股（市值<200亿），权重股跌幅明显偏弱        │
│      □ 无明确外部触发事件（无政策/地缘/禁令事件对应）              │
│      □ 两融标的跌停占比显著高于非两融标的                         │
│                                                                   │
│    → ≥2 项满足 → 判定为流动性恐慌 → 归因为 M 下降（非w_macro）    │
│       → 直接跳转至 5.6.5 情绪性响应（持有不动，不进入5.6.4）      │
│    → <2 项满足 → 判定为真实宏观恶化 → 归因为 w_macro 下降         │
│       → 进入 5.6.4 系统性响应（减仓）                             │
│                                                                   │
│  第三步：确认为M波动（情绪性回调）                                 │
│    □ 主矛盾全部intact（渗透率↑/催化在轨/护城河完整）               │
│    □ 跌幅无基本面对应（无公告/无研报变化/无产业链变化）             │
│    □ 融资/ETF调仓/量化清盘等资金面因素可解释                       │
│                                                                  │
│    → 全部确认 → 归因为M下降 → 进入5.6.5 情绪性响应                │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

#### 5.6.3 V下降响应（期权价值缩水）

**V下降必须先做性质判断，再做程度判断。**

##### 第一步：V下降性质判断（临时性 vs 结构性）

| 判断维度 | 指向临时性 | 指向结构性 |
|---------|----------|----------|
| **研发投入** | 持平或增加（管理层没放弃） | 大幅削减（管理层在收缩） |
| **毛利率** | 稳定或小幅下滑（产品没变） | 大幅崩塌（产品被替代） |
| **行业同行** | 同赛道公司增长（行业健康） | 同行也跌（行业系统性衰退） |
| **客户行为** | 订单延迟可解释（如军方财政节奏） | 客户永久切换至竞对 |
| **催化剂** | 延期但未取消 | 被证伪（新政策/技术颠覆） |
| **护城河** | SCP intact（追赶窗口仍在） | 竞对量产突破（追赶窗口关闭） |

**判定规则：**
- ≥4 项指向临时性 → V下降-临时性（SCP intact，短期内可逆）
- ≥4 项指向结构性 → V下降-结构性（SCP 受损，长期不可逆）
- 中间 3:3 → 先保守按结构性处理，新证据出现后再修正

**核心指标：研发投入。** 如果营收下滑时研发投入不变甚至增加，说明管理层不认为是永久性问题。这是最重要的单一信号。

##### 第二步：V下降程度与响应

| V下降性质 | V下降程度 | 判断标准 | 动作 |
|----------|---------|---------|------|
| **临时性** | 轻微 | 催化延期但未取消；单季miss但趋势未变；SCP完整 | 减仓至f*/3，设30日观察期 |
| **临时性** | 显著 | 连续2季miss；营收增速<行业均值；但SCP仍完整 | 减仓至f*/4（观察仓），等待Q+1数据反转 |
| **结构性** | 严重 | 催化被证伪；SCP受损；毛利率崩 >15pct；比2条指向结构性 | **转入Type B证伪流程 → 3-5日清仓** |
| **结构性** | 致命 | 核心催化剂被100%证伪；政策完全逆转；产品被淘汰 | **Type B立即清仓（不等3日）** |

**临时性V下降的恢复条件（任一满足=恢复）：**
- 下一个季度营收恢复正增长（YoY>0）
- 催化剂有新进展（订单/产品认证/新项目确认）
- 行业数据恢复增长（同赛道公司集体回暖）
→ 恢复后仓位可加回至f*/3（不等完整评估）

**临时性V下降超过2个季度未恢复 → 转结构性处理（Type B清仓）**

#### 5.6.4 系统性响应（w_macro下降）

| Regime变化 | 动作 | 逻辑 |
|-----------|------|------|
| R1/R2 → R3 | 减仓至f*/2，不清仓 | 系统性放缓，但公司基本面无损 |
| R2/R3 → R4 | 减仓至f*/4，仅保留核心仓位 | 熊市早期，保存资本 |
| 任意 → R5 | 按Type A4处理 | 系统性危机 |
| 大盘急跌但Regime未变 | 持有，不操作 | 脉冲式波动，非趋势性 |

**关键原则**：w_macro下降时**绝不清仓优质标的**（除非R5）。原因：Regime会恢复，但卖出后能否买回同一位置不确定。减仓是为了心理承受力和组合风控，不是因为论据失效。

#### 5.6.5 情绪性响应（M下降 = 最重要的场景）

**核心结论：M下降时不卖出。**

| 回撤幅度 | M下降确认后的动作 | 附加条件 |
|---------|-----------------|---------|
| -15%~-25% | 持有不动 | 不加仓，正常波动不值得动 |
| -25%~-40% | **持有不动 → 评估加仓条件** | 详见下方加仓 SOP |
| -40%~-50% | 持有不动，仓位上限锁定 | 承认可能有未知信息 |

> **V18.2 加仓 SOP（结构化加仓规则，非必须执行）**

当 M 下降确认且满足以下 **三个条件** 时，可以作为特例考虑加仓：

| # | 条件 | 阈值 | 逻辑 |
|:-:|:----|:----|:----|
| ① | 回撤幅度 | 从持仓高点 > **25%** | 不到 25% 不值得加 |
| ② | 主矛盾强度 | PTS ≥ **0.80** | 逻辑不硬不摊平 |
| ③ | 仓位空间 | 当前仓位 + 加仓量 ≤ **f*** | 不超 Kelly 上限 |

**三条件全满足时 → 可加仓 f*/4（满仓 Kelly 的四分之一）**

**禁止加仓条件（任一触发→不加）：**
- Type R 归因不是 M 下降
- 回撤 < 25%
- PTS < 0.80
- 仓位已达 f* 上限
- 近 6 月涨幅已 > 150% 且 PEG > 2.0
- Regime 已恶化至 R4/R5
| >-50%（已触发资本保护线） | 已减半仓，剩余继续持有等诊断 | 若诊断确认M→减半仓可择机回补 |

**M下降时的加仓决策**：

```
加仓条件（全部满足）：
1. V/M/w归因诊断确认为M下降（72小时协议完成）
2. 主矛盾4项全部intact（有具体证据，非"没看到坏消息"）
3. 仓位<f*（有加仓空间）
4. 下跌幅度>-20%且PTS≥0.75
5. Regime仍为R1/R2

加仓幅度：回撤加仓不超过f*/4（总仓位不超过f*×0.75）
```

#### 5.6.6 -50% 资本保护线

无论归因结果如何，回撤>50%时执行：

```
立即减半仓（不等诊断完成）
理由：
  - 即使V完全intact，-50%意味着你对timing的判断严重失误
  - 50%亏损需要100%涨幅才能回本→资金效率急剧下降
  - 承认"可能有你不知道的信息"→先保存资本

减半仓后：
  - 如72小时诊断确认V intact + 仅M波动 → 剩余50%继续持有，不再减
  - 如诊断发现V下降 → 剩余仓位按Type B/C处理
  - 如后续恢复到-30%以内 + V确认intact → 可回补减掉的仓位
```

### 5.7 卖出决策优先级

```
Type A (物理硬约束) > Type B (主矛盾证伪) > Type C Level 3 > Type R-V下降 > Type D (止盈) > Type C Level 2 > Type R-w下降 > Type C Level 1
```

**注意**：Type R的M下降响应优先级最低（因为结论通常是"不卖"）。

### 5.8 卖出后操作

| 卖出类型 | 后续操作 |
|---------|---------|
| Type A | 30天冷静期，不买回 |
| Type B | 30天冷静期，除非有全新催化剂且重走完整SOP |
| Type C Level 3 | 同Type B |
| Type C Level 2 | 保留在观察池，月度跟踪。如恢复可重新建仓 |
| Type D | 部分止盈后剩余仓位继续持有，正常月检 |
| Type R（V下降减仓） | 保留在观察池，等V修复信号 |
| Type R（w下降减仓） | Regime恢复后优先回补 |
| Type R（资本保护线减仓） | 诊断完成后决定：M确认→可回补，V确认→转Type B |

### 6.1 月度强制检查清单

每月第一个交易周，对持仓中**每只标的**执行以下13项检查：

#### 6.1.1 价格行为健康度（4项）

| # | 检查项 | 绿色（通过） | 黄色（警告） | 红色（降级） |
|---|--------|------------|------------|------------|
| 1 | MA20 vs MA60 | MA20>MA60，MA20斜率>0 | MA20持平或走平>5日 | MA20下穿MA60 |

#### 6.1.2 基本面验证（4项）

| # | 检查项 | 绿色 | 黄色 | 红色 |
|---|--------|------|------|------|
| 5 | 渗透率P进展 | 季度数据确认加速或稳定 | 无新数据（1季度内可容忍） | 渗透率增速下降>50%或停滞2季 |
| 6 | 行业月度数据 | 订单/出货/报价趋势不变 | 部分指标走弱但核心稳 | ≥2个前瞻指标同步转负 |

#### 6.1.3 资金面与情绪（3项）

| # | 检查项 | 绿色 | 黄色 | 红色 |
|---|--------|------|------|------|
| 9 | 机构持仓ΔQ | ΔQ>0或稳定 | ΔQ轻微下降(<3pct) | ΔQ<-5pct |
| 10 | 融资余额变化 | 稳定或增长 | 下降<10% | 下降>20% |

| # | 检查项 | 绿色 | 黄色 | 红色 |
|---|--------|------|------|------|

- 13项全绿 → 继续满仓

- 红色≥2项 → 直接Type C Level 3

### 6.2 个股定制领先指标

每只标的在建仓时确定2-3个**特有的**领先指标。

**设计原则**：
1. 时间领先性：比季报至少早1-2个月可观测
2. 因果强相关：该指标变化→直接影响公司收入/利润
3. 可获取性：有公开数据源，可月度追踪

**行业领先指标模板**：

| 行业 | LI-1 | LI-2 | LI-3 |
|------|------|------|------|
| AI算力/PCB | 北美四大CSP CapEx指引 | GPU出货量/数据中心开工 | 公司月度营收(若披露) |
| 半导体设备 | SEMI月度BBR | 晶圆厂招标/中标公告 | 合同负债季度变化 |
| 模拟芯片 | 渠道库存周转天数 | 汽车/工业新客户导入 | 同行月度营收趋势 |
| 创新药 | 处方量/入组速度 | 学术会议数据 | 竞品临床进展 |
| 军工 | 军费执行率 | 外贸订单签约 | 配套企业收入 |
| 机器人 | 特斯拉/头部厂商进展 | 核心零部件出货 | 订单数据 |

### 6.3 魔鬼辩护（Devil's Advocate）模板

**使用时机**：建仓时（必做）+ 每季报后（必做）+ 月检出现黄色时（可选）

对每只持仓标的回答5个问题：

#### DA-1: 趋势逆转论
> "如果这个行业趋势在6个月内被逆转，最可能原因是什么？有没有早期信号？"

检查：技术路线替代 / 需求端见顶 / 政策变化 / 供给过剩

#### DA-2: 护城河侵蚀论
> "竞争对手要攻破护城河，最可能路径是什么？进展到哪一步了？"

检查：技术追赶阶段 / 客户突破阶段 / 规模追赶阶段 / 认证突破阶段

**⚠️ 修正规则：P_eff < 10% 时 DA-2 评分调整**

```
在 P_eff < 5% 的市场中，不存在「护城河深」的公司——
因为没有市场就没有先行者，所有人都是挑战者。
此时用「现有护城河深度」判断会系统性低估新市场的可能性。

修正逻辑：
  IF P_eff < 10% AND 公司是该新市场中最早实现量产的少数企业之一:
      DA-2 护城河评分 +0.10
      原因：P<10% 阶段，没有「被挑战」的基础——
            谁是第一个大规模量产的，谁就在建立护城河，
            不是在「防守」护城河。

  IF P_eff < 5% AND 公司是该新市场的第一个量产企业:
      DA-2 护城河评分 +0.15
      原因：独家量产 6-12 个月的时间窗口就是护城河。
            竞对从研发→验证→量产至少需要 12-18 个月。
```

> **示例——龙磁科技（芯片电感，P<5%）：**
> 原 DA-2=0.65（「公司在芯片电感领域是挑战者而非被挑战者」→ 扣分）
> 修正：P<5% + 首个国际半导体客户中标量产 → DA-2+0.15 → 0.80
> 原 DA-Total=0.55 → 修正后≈0.63（从「高风险不入场」变为「可入场但小仓位」）
> MB 从 0.67 → ~0.72（过 2x 线）

#### DA-3: 盈利失望论
> "下季报如果miss，最可能原因是什么？概率多大？"

检查：毛利率 / 确认延迟 / 费用超支 / 汇兑 / 减值 / 一次性消失

**财务毒丸专项检查（新增）：**
> 以下两项均基于量化数据，不靠定性判断。

```
□ 应收账款增速 > 营收增速？
  （应收账款占营收比重持续上升 = 公司在用垫资换增速）
□ 存货减值同比加速计提（增速 > 50%）？
  （存货在贬值 + 下游需求可能放缓）

→ 若两项均为「是」：DA-3 评分 -0.10
→ 若仅一项为「是」：标注「财务健康度警告」但不调整分数
→ 若两项均为「否」：正常
```

> **示例——江海股份**：应收账款 23.65 亿占年化营收 42.7%，应收账款增速 > 营收增速；Q1 存货减值同比+240%。两项均触发 → DA-3 评分 -0.10。
